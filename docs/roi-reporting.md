# ArborLine Connect ROI reporting

The client portal reports a simple revenue ROI based on customer-reported recurring monthly contract value.

- Clients can attach an optional estimated monthly value when updating a handoff outcome.
- Dashboard funnel: qualified matches → handoffs → estimates → wins.
- Open estimate value sums handoffs currently marked `ESTIMATE_SENT`.
- Won monthly value sums handoffs marked `WON`.
- Revenue multiple = won monthly value / $750 Founding Client monthly fee.
- Revenue ROI = (won monthly value - $750) / $750.

This is revenue ROI, not profit ROI. It does not subtract service-delivery costs and is only as complete as the values clients report.
